# 🩺 麻醉備物溝通看板｜麻醉醫師使用說明

彰化秀傳麻醉科 OR 內部備物溝通工具。麻醫輸入備物需求，護理師即時看到、即時備物。

## 📱 網址（建議加到手機書籤）

**麻醉醫師完整版**
👉 https://anesthesia-prep-board.netlify.app/

手機、平板、醫院電腦皆可開，不用安裝任何 app。

---

## 🚀 第一次怎麼用（30 秒上手）

1. **選班別**（最上方）：白班前段 / 白班後段 / 值班
   - 選了之後，下方 Room 按鈕只顯示該班別的房間
   - app 會記住你最後選的班別，下次打開不用再選

2. **新增 case**（從上到下填）：
   - Room（依班別過濾）
   - 第幾台（第1~4台 / 急診插入 / 其他）
   - 年齡 / 性別
   - 科別 → 術式（科別點選後自動跳出對應術式按鈕，也可自填）
   - 麻醉方式（GA / SA / IVG / EA）
   - **Airway 備物**（LMA / Non-kinking endo / 鼻管）
   - **Monitoring 備物**（BIS）
   - **止痛備物**（NB / Testing / Spinal morphine / Dynastat / Acetamol / Epidural PCA / IVPCA）
   - 特殊提醒（高風險、需 A-line、需 CVC、需 DLT、困難 airway…）
   - Hx（病史）、Data（異常指標）
   - 備註
   - 按「送出到看板」

3. **看板分頁**：點底部「📊 看板」就看到所有 case 卡片，依房間和狀態分組。

## ✨ 用起來會很爽的小功能

### 🎯 術式自動帶入特殊提醒
選了某些術式會自動勾選對應的特殊提醒，不用每次重點：

| 術式 | 自動帶入 |
|---|---|
| Lobectomy | 需 A-line、需 DLT、ICU postop |
| Esophagectomy | 需 A-line、需 DLT、需粗 line、ICU postop |
| 切肝 | 需 A-line、需 CVC |
| CABG / AVR / MVR | 需 A-line、需 CVC、ICU postop、術後呼吸器 |
| Craniotomy | 需 A-line、ICU postop |
| free flap | 需 A-line、需 CVC |
| ⋯（還有十幾項，看狀況自動帶） |

帶錯了直接點掉即可。

### 🔗 困難 airway 自動補 FOB
勾選「困難 airway」會自動補勾「需 FOB」（備 fiber）。

### 🔀 跳房
case 在看板上有「🔀 跳房」按鈕，點選新的 Room 即可。看板會顯示「⚠️ R5 → R8」提醒護理師。

### ✓ 一鍵清「尚未麻評」
特殊提醒勾了「尚未麻評」的話，看板卡片上會有個綠色「✓ 已評估」按鈕，做完麻評點一下就消失。

### ✎ 編輯重開表單
不滿意點「✎ 編輯」，會跳回新增表單把資料全部預填好讓你改。

### 📥 CSV 匯出
看板右上「📥 匯出 CSV」可下載整天紀錄（不含病人個資），Excel 打開即可。

## 🔄 跨裝置即時同步

- 你在電腦輸入後，護理師的手機 1 秒內就看到
- 麻醫之間互相也看得到（例如交班）
- 上方有「☁ 雲端同步中」綠色 badge 表示連線正常
- 如果變紅色「⚠ 離線模式」表示連不到雲端（這時只有自己這台會存，網路通了會自動補上）

---

## 🔒 重要安全規則

1. **不要輸入**病人姓名、病歷號、身分證、完整 lab 或 HIS data
2. 備註欄上限 80 字，placeholder 也有提醒
3. 每天 23:59 全部資料自動清除（雲端 + 所有裝置都清）
4. 隔天打開若資料是昨天的會自動清掉
5. 這個工具**不是病歷紀錄、不是醫囑**，只是備物溝通

## ❓ 常見問題

**Q：手機看到一直「連線中」？**
A：通常是醫院 wifi 太忙或被擋。試試切到 4G/5G，或重新整理頁面。

**Q：我改了一筆資料但別台沒更新？**
A：通常 1~3 秒就同步。如果超過 10 秒沒同步，重新整理對方的頁面試試。

**Q：今天下午突然資料消失了？**
A：可能不小心按了右上「重置全天」（會問你確認）。或是日期跳到隔天了（23:59 自動清）。

**Q：開新 case 不小心送出，要怎麼刪？**
A：看板上每張卡都有「刪除」按鈕（會問你確認）。

**Q：值班晚上的 case 隔天會被清掉嗎？**
A：每天 23:59 全部清掉。如果有跨夜 case，建議晚上 23:30 之前用 CSV 匯出留存。

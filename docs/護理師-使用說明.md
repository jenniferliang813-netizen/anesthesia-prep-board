彰化秀傳麻醉科 OR 內部備物溝通工具。麻醫輸入備物需求後，你在這裡即時看到要備什麼。

## 📱 網址（建議加到手機書籤）

**麻醉護理師看板**
👉 https://anesthesia-prep-board.netlify.app/board/

手機、平板、醫院電腦皆可開，不用安裝任何 app。

## 🚀 怎麼用（10 秒上手）

1. 打開上面網址
2. 最上方選班別（白班前段 / 白班後段 / 值班）
3. 看到所有今日 case 的卡片
4. **手術中** 的 case 排在最上面，**待手術** 次之，**已完成** 排最下面

就這樣 ✨

## 🔍 卡片上你會看到什麼

```
[手術中]  第2台｜CS｜Lobectomy｜GA｜45M
⚠️ 跳房：R5 → R8

Airway：LMA、HFNC
Monitoring：BIS、CVP kit
備藥：Propofol TCI、Remifentanil TCI、Etomidate
NB：ESP block
Ropivacaine 5 ml + Decadron 1 ml + Epinephrine 0.1 ml
用 D5W 稀釋至 20 ml，抽 2 隻
Testing：
Lidocaine 1 ml
用 Normal saline 稀釋至 5 ml，抽 1 隻
PCA：IVPCA
Systemic analgesics：Dynastat、Acetamol

⚠️ 需 A-line、需 DLT、Post OP ICU

▸ Hx (3)  ▸ Data (2)

[▶ 進入手術] [🔀 跳房]
```

### 解讀
- **[手術中] / [待手術] / [已完成]**：左上角圓形 badge 是手術目前狀態
- **第2台**：今天這個房間第 2 台刀
- **CS｜Lobectomy｜GA**：科別、術式、麻醉方式
- **45M**：45 歲男性
- **⚠️ 跳房**：本來在 R5、改去 R8 開
- **Airway / Monitoring / 備藥**：要備的呼吸道器材、監測器材、藥物
- **NB 配方**：每隻針筒同樣配方，總共抽幾隻
- **Hx / Data**：病史與異常指標（按 ▸ 展開看細節）

## 🎯 你可以做的操作

### 1. 切換班別
最上方按鈕：白班前段 / 白班後段 / 值班，會記住你的選擇。

### 2. 標記手術狀態
每張 case 卡片底部有按鈕：

| 卡片狀態 | 顯示的按鈕 | 點下去後 |
|---|---|---|
| 待手術 | ▶ 進入手術 | 變成「手術中」 |
| 手術中 | ✓ 已完成手術 | 變成「已完成」 |
| 手術中 | ↺ 回待手術 | 退回「待手術」（誤按修正用） |
| 已完成 | ↺ 回手術中 | 退回「手術中」（誤按修正用） |

也可以直接點左上角的 **狀態 badge** 循環切換：待 → 中 → 完成 → 待。

### 3. 跳房
case 臨時跳到別的房間？點「🔀 跳房」→ 選新的 Room 號碼。所有麻醫的看板上也會立刻看到「⚠️ R5 → R8」提示。

### 4. 展開 Hx / Data
卡片中間有「▸ Hx (3)」「▸ Data (2)」這種小膠囊，點一下會展開看詳細內容（HTN, DM, EF<40 等）。

## 🔄 跨裝置即時同步

- 麻醫在他的手機輸入完，你的手機 1 秒內就看到
- 你按了「進入手術」/「完成」/「跳房」，麻醫也 1 秒內看到
- 上方有「☁ 雲端同步中（即時更新）」綠色 badge 表示連線正常
- 變紅色「⚠ 離線」就是連不到雲端，重新整理或檢查網路

## ❓ 常見問題

**Q：我看不到任何 case？**
A：可能麻醫還沒輸入，或者你選的班別跟麻醫不同。試試切到「值班」看全部房間。

**Q：手機顯示「連線中」一直轉？**
A：醫院 wifi 不穩。切到 4G/5G 試試，或重新整理頁面。

**Q：剛剛我按「完成」是不是誤按？想退回？**
A：對該 case 卡片直接按「↺ 回手術中」即可，也可以點左上角 badge 循環回去。

**Q：跳房按錯怎麼辦？**
A：再按一次「🔀 跳房」選回原本的 Room 即可。

**Q：今天的資料明天還會在嗎？**
A：每天 23:59 全部清掉，隔天打開是新的一天。

**Q：可以從這裡看到病人姓名嗎？**
A：**完全沒有**。系統本來就不收姓名 / 病歷號 / 身分證，純粹溝通備物需求。
